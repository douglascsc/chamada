  1. Acesse o SUAP.
  2. No menu, acesse Ensino → Turmas e Diários → Meus Diários.
  3. Localize e acesse a turma desejada.
  4. Selecione a opção Imprimir Relação de Alunos.
  5. Salve o arquivo gerado em PDF.
  1. Envie o PDF para um assistente de IA (ex: ChatGPT).

Liste exclusivamente os alunos da turma.

Regras obrigatórias:
- Não use numeração.
- Não use marcadores (-, •, etc.).
- Não use aspas.
- Não use vírgulas ou ponto e vírgula para separar os nomes.
- Não inclua matrícula, e-mail, curso, turma ou qualquer outra informação.
- Não escreva títulos, introduções ou explicações.
- Não coloque texto antes ou depois da lista.
- Preserve exatamente a grafia dos nomes, incluindo acentos, cedilha e sobrenomes.
- Não altere, abrevie, corrija ou reordene os nomes.
- Cada linha deve conter um único nome de aluno.

Formato esperado:
Aluno 1
Aluno 2
Aluno 3

A resposta final deve conter apenas a lista de nomes, sem qualquer texto adicional.

Avisos importantes — leia antes de usar

Resumo para o professor.

1. Isto é um apoio, não substitui o SUAP

Este sistema foi feito para facilitar o controle do dia a dia em sala de aula. Ele não substitui os sistemas institucionais — a chamada oficial continua sendo lançada normalmente no SUAP, sempre depois de você validar os dados. Não confie apenas nos registros deste app como prova definitiva de frequência: vale sempre conferir também por chamada oral/visual em sala.

2. Dados pessoais tratados (LGPD)

O sistema trata dados pessoais de alunos: nome, turma, e registros de presença (nome, data, horário e um identificador do aparelho usado para marcar). Isso fica salvo no Firestore do projeto Firebase usado por este site — não fica no GitHub. As fotos de comprovantes de atraso que você guardar (botão "📷 Atrasos") também ficam lá, visíveis só para você (e para a conta master do sistema), e são apagadas automaticamente após 180 dias. Cabe a você observar as políticas internas de proteção de dados e a LGPD ao usar esta ferramenta, incluindo avisar os alunos sobre esse tratamento, se for exigido.

3. Segurança — o que é garantido e o que não é

  • O identificador de aparelho ("um aluno por celular, por dia") pode ser contornado por alguém que limpe os dados do navegador ou use outro aparelho/aba anônima.
  • A presença é marcada pelo próprio aluno, sem verificação de identidade — nada impede, tecnicamente, que uma pessoa marque a presença de outra.

Por isso: não cadastre alunos com dados sensíveis além do nome, e trate a chamada deste sistema como um apoio operacional, nunca como prova incontestável.

4. Em caso de dúvida ou problema

Fale com douglascamargo@ifsul.edu.br. O sistema está em fase de testes.
